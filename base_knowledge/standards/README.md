# Standards

This directory contains development standards that are **reasoned and derived**
from the actual source code of this project. These are not generic guidelines —
they reflect patterns actually used in this codebase.

Includes:
- DTO naming and structure standards
- Logging standards (format, level, best practices)
- Exception handling standards (error codes, throw patterns)
- Database interaction standards (repository patterns, ORM usage)
- Error code naming standards

**Naming convention**: `<standard-name>_standards.md`

Examples:
- `dto_standards.md`
- `logging_standards.md`
- `exception_standards.md`
- `database_standards.md`
- `error_code_standards.md`
