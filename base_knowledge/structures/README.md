# Structures

This directory contains architecture documentation for each service/module
in the system, each with visual Mermaid.js diagrams.

**Naming convention**: `<service-name>.md`

Each file MUST contain:
1. Primary responsibilities (what business problem does this service solve)
2. Dependencies (upstream/downstream services)
3. Key processing flow (critical classes and how data flows through them)
4. Visual diagrams (Mermaid.js sequence + architecture diagrams)
