# Release 3 - Admin Portal (Tương lai)

> **Mục tiêu:** Vận hành hệ thống với admin portal, duyệt BS, dashboard.
> **Sprint:** 4 (tương lai) | **Thời gian:** Chưa xác định
> **Tổng:** 7 User Stories (US-26 đến US-32)

---

## Phạm vi dự kiến

Theo Product Backlog ban đầu, Release 3 bao gồm:

- Admin portal
- Duyệt bác sĩ
- Dashboard thống kê
- Cấu hình rule (Triage, gán BS)

## User Stories dự kiến

| US ID | User Story (dự kiến) | Epic |
|-------|---------------------|------|
| US-26 | Là Admin, tôi muốn đăng nhập vào admin portal | Admin |
| US-27 | Là Admin, tôi muốn duyệt tài khoản bác sĩ mới | Admin |
| US-28 | Là Admin, tôi muốn xem dashboard thống kê ca bệnh | Admin |
| US-29 | Là Admin, tôi muốn cấu hình rule Triage | Admin |
| US-30 | Là Admin, tôi muốn cấu hình rule gán BS | Admin |
| US-31 | Là Admin, tôi muốn quản lý người dùng (BN/BS) | Admin |
| US-32 | Là Admin, tôi muốn xem báo cáo hoạt động hệ thống | Admin |

*Ghi chú: Các US-26 đến US-32 chưa được chi tiết hóa. Cần Sprint Planning khi bắt đầu Sprint 4.*

## Trạng thái

Release 3 chưa được triển khai. Sản phẩm hiện tại (Release 1+2) đã đạt yêu cầu MVP và sẵn sàng cho phát triển tiếp.

## Tiên quyết

- Release 1 + 2 đã hoàn thành (25/25 US, 75/75 SP)
- 5 Issues Minor/Cosmetic từ Sprint 3 cần xử lý
- CI/CD pipeline cần thiết lập
- Integration Test tự động cần bổ sung
